# 🤖 DailyRoutine AI — Smart Daily Routine & Task Manager

DailyRoutine AI is an interactive personal productivity and task management application designed to help users organize, monitor, and improve their daily routines. The application allows users to create and manage tasks with specific dates, times, priorities, categories, and recurring schedules. It provides a centralized dashboard where users can easily view their daily activities and track their progress.

The main feature of DailyRoutine AI is its AI-powered task monitoring assistant. The assistant analyzes the user's scheduled tasks and provides useful information about upcoming, pending, and completed activities. It can suggest what task the user should focus on next and provide personalized reminders based on the daily schedule. The chatbot can also be integrated with the task database to make task management more interactive.

The application includes desktop notifications that remind users when a scheduled task is approaching or becomes due. This helps users stay focused and reduces the chance of forgetting important activities. Users can mark tasks as completed, monitor their daily completion percentage, and review their overall productivity.

### ✨ Key Features

* 📅 Daily and weekly task management
* ⏰ Date and time-based scheduling
* 🔔 Desktop notifications and reminders
* 🤖 AI-powered task monitoring chatbot
* ✅ Task completion tracking
* 📊 Daily productivity progress
* 🔁 Recurring tasks
* ⚡ Priority levels
* 📂 Task categories
* 🧠 Smart routine suggestions
* 💾 Persistent SQLite database
* 🔍 Task filtering and organization
* 🖥️ Interactive Streamlit dashboard

### 🛠️ Technologies Used

Python, Streamlit, SQLite, Pandas, Windows Toast Notifications, and AI/NLP technologies.

### 🎯 Project Objective

The goal of DailyRoutine AI is to create a personal digital assistant that goes beyond basic task management. It combines scheduling, notifications, progress tracking, and AI-based assistance to help users build consistent routines, manage their time effectively, and complete their daily responsibilities.
